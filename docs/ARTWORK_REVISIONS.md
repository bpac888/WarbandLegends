`data/portrait-revisions.json` records the original and approved portrait hashes. Build and historical roster checks validate the approved bytes, then use the original hash for expansion-era fingerprints. This allows an explicitly requested portrait edit while preserving checks for every other historical portrait. Unregistered changes and unapproved replacements still fail validation.
