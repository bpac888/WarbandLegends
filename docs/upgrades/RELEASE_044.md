# 0.44.0 — readable statuses and battle feedback

- 31 original colorful 256px status illustrations, one per buff, ailment, elemental DEF reduction and instant action. Shared by battle badges, character details and the Effects guide; production assets total about 581 KB.
- Larger active-effect images on cards, no visible turn counters. Tapping a badge or inspecting a unit shows its effect names, durations and rules. Hero badges form a compact side rail; enemy badges sit below the health/mana area. Crowded rails scroll without resizing cards.
- Enemy artwork is slightly smaller; the board has tighter visual gaps while tile input hit areas and swipe behavior remain intact.
- Poison, Burn, Frostbite and Bleed use distinct impact colors/shapes and their matching icon beside actual damage amounts. Strength/critical labels appear only when present in the combat event. Healing remains green. Defeats produce a brief portrait dissolve and outward light shards.
- New visuals read battle events and never change damage, buffs, rewards or saved state. Reduced Motion suppresses bursts/dissolves and keeps damage numbers static. Navigation clears effects. Rune projectiles now remain visible for colors whose champions have fallen, matching the existing damage rule.
- Guide copy is brief, uses familiar abbreviations without definitions, and consolidates repeated DoT/elemental DEF rules. Each effect entry uses its new image. No added how-to explanations; detailed character-effect descriptions retain full rules.

Validation: full unit suite/build; unique art hashes and effect coverage; actual DoT/critical/defeat event parsing; phone, desktop and landscape badge layouts; no card counters; active-effect details; damage/death visuals; reduced motion, cleanup and unchanged battle state; all guide artwork decoding. Original game screenshots were used as inspiration for clarity, not copied.
