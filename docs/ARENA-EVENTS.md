# Arena, Special Events and the Altar · v0.9

> Current economy/save rules: [Gems and account journey (v0.15)](GEMS-QUESTS.md). Seals and older save migration notes below describe earlier releases.

Legends now has nine playable Arena rivals, each with four champions and seven covered attack lanes. These are local preset defense teams adapted from Warband Legends, not online players. Wins award gold, Arena Tokens and 18 rating; losses subtract 12 rating. Results settle once, including after reload.

Special Events use America/Los_Angeles calendar dates every month: Crimson Eclipse 1–8, Frostwake Siege 9–16, Veil of Umbra 17–24. Each window has 20 attempts, paid when a real challenge starts. Leaving or losing does not refund an attempt. A saved challenge can finish after its entry window closes. There is no event practice button or out-of-window entry. The existing global open-roster testing setting still disables rewards; use Collection mode for normal progression.

Each event reuses its original illustration and boss identity. Event wins award eight corresponding tokens, gold and participating-hero XP, with an initial-clear seal. The Supply Exchange accepts Arena Tokens and event tokens for seals, or Arena Tokens for training gold; purchases show a confirmation and exact cost.

The Altar adapts the owner's original summoning page and SummonPortal animation. One pull costs one seal; ten pulls cost nine seals, with at least one Rare or better. The champion remains absent during the initial 1.5-second portal activation, then emerges through the original layered swirls, sparks and light. Skip shows the saved results; it never purchases a second batch. Reduced motion skips the ritual. Rarity odds and the ten-pull guarantee are disclosed on the page.

The Citadel's four destination cards reuse the original Tavern illustrations for the Altar, Adventure, Codex and Supply Exchange. All reused art is local, optimized WebP embedded in SVG wrappers. The original repository and services remain untouched.

Profile schema 7 adds mode resources to schemas 5/6 without resetting collection, levels, campaign, dungeon progress or saved fights. All 135 champion IDs and existing core combat rules are preserved. This remains an independent local game; event dates and saves use the player's browser, with no server authority or online multiplayer yet.
