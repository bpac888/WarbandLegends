# Legendary Artwork Refinements and Four Rare Changes

Auroline, Azure Sovereign, Baron Viktor, Berserker Loki, Executor Model Z, Hexandra, Jarl Bjorn, Ossir, Selka the Wraith, the Oracle and Vharos receive reference-based portrait refinements. Their existing current portraits are the explicit image-edit inputs. The brief preserves character identity, overall design, palette and theme while improving fine detail and rendering. Gameplay is unchanged for these eleven Legendaries.

Dragon Samurai Kenshin, Chem-Tank Brax, Quill (the Plague Sovereign) and the Shade Prince become Rare. Their portrait files, names, factions, roles and elements are unchanged. Stats use Rare baselines; all four charge at Average speed (10 tiles).

Rarity-based summons, feeding, ascension costs, level caps and two Limit Breaks use the existing rules. Summon probabilities are unchanged. Current roster: 189 champions (27 Common, 66 Rare, 79 Legendary, 17 Mythical). Existing saves use normal normalization; the owner permits progress changes resulting from the new rarity caps. Other character records are unchanged.
