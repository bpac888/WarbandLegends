# Independent game roadmap

1. **Playable PvE foundation (this version):** reusable champion identities and art, five-color match-3 combat, five-hero teams, signature skills, specials, enemy turns, local progression, responsive interface and tests.
2. **Content and balance:** playtest the three encounters, refine damage/mana pacing, add chapter maps and boss encounters, improve character attack animation assets, and tune puzzle-specific ability descriptions. Portraits currently animate; true articulated sprites or 3D characters require a separate asset pipeline.
3. **Collection and progression:** define this game's own starter roster, summon pools, earned currencies, duplicate/trainer feeding and skill leveling. Keep all balances and saves independent from Warband Legends.
4. **Online foundation:** new backend/database, authentication, authoritative combat/rewards, save migration, hosting and abuse controls. This step is required before trusted shared economies or competitive rankings.
5. **Community:** asynchronous raids and defenses, alliances, cooperative bosses and wars after the online foundation is proven.

Later phases are design scope, not implemented features. No existing Warband Legends account, inventory, currency, deployment, repository, or database is migrated or modified by this project. The v0.2 roster now has individually assigned colors, one merged Special per champion, tile-based mana categories and multi-level charging. Further balance remains independent of the original game.
